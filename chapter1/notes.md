## Introduction to low level languages

- Low level language programs are not portable. Each is tailored to specific instruction set architecture. 
- Each architecture has their own way of quirks, different registers/design
- Low level languages are fast <- primary benefit

## Introduction to high level languages

- C, C++, Pascal
- Must be translated to machine language
- C++ programs must be compiled -> reads high level language and translates to machine code
- Compilers package into executable files

- - Warning: Should not do
